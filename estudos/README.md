# Estudos Tecnicos

Esta pasta centraliza material de estudo para aprendizado de Go e arquitetura de servidor MMORPG.

## Objetivo

- Separar documentacao de aprendizado da documentacao de produto.
- Manter trilhas praticas ligadas ao codigo real do repositorio.
- Facilitar revisao incremental apos cada fase de implementacao.

## Estrutura

- [go/00_trilha_go.md](go/00_trilha_go.md): ordem sugerida de estudo.
- [go/01_conceitos_base.md](go/01_conceitos_base.md): base de Go usada no servidor.
- [go/02_lobby_websocket_na_pratica.md](go/02_lobby_websocket_na_pratica.md): leitura guiada do lobby atual.

## Como usar com este repositorio

1. Ler um topico da trilha.
2. Abrir os arquivos de codigo citados.
3. Rodar o servidor e testar localmente.
4. Voltar no material e anotar duvidas para a proxima iteracao.
